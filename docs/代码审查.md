## 1. 导入时 .nhlrc 无效不会回退到 .lrc

- 优先级：中
- 状态：⬜ 待修
- 位置：`core/importing.py`

### 现状

`_pick()` 先选 `.nhlrc`，再选较新的 `.lrc`。主配对路径只校验选中的那一个：

```python
lrc = _pick(cand)
ok, _why = LRC.valid_import(raw)
if not ok:
    pending.append(str(a))
    added.append(str(a))
    continue
```

如果目录里同时有：

```text
歌曲.nhlrc   ← 损坏/不合法
歌曲.lrc     ← 合法
```

会选中 nhlrc，校验失败后直接放弃，不会尝试 lrc。

### 修复方向

```text
按候选顺序逐个校验
第一个 valid_import 通过的文件才使用
```
