## 阅读顺序建议

```text
第一次接触     README 的「一页摘要」→ 实现状态表 → docs/eval.md
要动手改        docs/testing.md → 对应模块的文档 → docs/NOTES.md 里相关小节
要判断可行性    docs/NOTES.md（失败过的思路都记了数字，避免重复试错）
```

## 一句话分工

```text
README    设计（应该怎样）
eval      评测（现在怎样）

player    播放器（用户看到的那层）
NOTES     历史（试过什么、为什么放弃）
```
