# 查看与播放：状态划分

> 读者：改播放栏、歌词区、波形、循环、重新匹配的人。
> 一句话：上方只操作“正在查看的歌 B”，下方只操作“正在播放的歌 A”。
> 例外只有：上一句/下一句/循环开关会把页面带回 A。

## 0. 两个对象

```text
B = 正在查看的歌
    NH.S / NH.LINES / 左侧歌词 / 右侧面板 / LRC 表格 / 波形 / header

A = 正在播放的歌
    NH.PLAYING / NH.au / 播放栏 / 播放条 / 时间 / 音量 / 音量后的循环
```

```text
两个 idx 不要求相同：
  查看 B、播放 A 是正常状态
  只有 B 自己就是 A 时，两个 idx 相同
```

## 1. 上方（B）

### 1.1 重新匹配歌词

```text
· 只按 B 的标题/歌手/时长搜索
· 候选、选中、写 nhlrc 都只改 B
· 不改 A 的播放位置、播放状态、歌词
· B 不在播放时，不产生任何音频动作
```

### 1.2 振假名选择 / 编辑

```text
· /api/line 用 B 的 idx
· 立即写 B 的 nhlrc
· 不碰 A
```

### 1.3 LRC 编辑模式

```text
所有编辑操作绑定 B。

单击歌词行：
  · 只改 B 的选中/当前行
  · 不 seek、不暂停、不切歌

双击歌词行：
  · 切到 B
  · 从该行开始播放
  · 留在 LRC 编辑模式

波形：
  · 显示 B 的波形
  · B 不在播放：静止
      播放头跟着 B 的当前选中行
      点波形 = 选中最近的行，不 seek A
  · B 正在播放：播放头跟音频
```

## 2. 下方（A）

### 2.1 上一句 / 下一句

```text
· 按 A 的歌词行算
· 自动把页面跳到 A（相当于在歌单里点 A）
· 再等同于点 A 的对应句：seek 到该行
· A 暂停时：跳页面、定位，但保持暂停
· 没有 A：按钮禁用
```

### 2.2 播放 / 暂停

```text
· 只切换 A 的播放状态
· 不切歌、不跳页面、不改 B
· 没有 A：按钮禁用
```

### 2.3 单句循环

```text
· 只对 A 生效
· 查看 B 时点击：先把页面跳到 A，再切换
· 播放 A、查看 B 时：单句循环自动关闭
· 关闭时清空 LOOP_ROW，按钮文字同步
```

### 2.4 单曲循环

```text
· 只对 A 生效
· 查看 B 时点击：先把页面跳到 A，再切换开关
· 换歌不自动关闭
```

### 2.5 没有 A 时

```text
禁用：
  上一句、播放/暂停、下一句、单句循环、单曲循环
  播放条上的播放/暂停、±10 秒、进度条
不禁止：
  「开始」按钮（显式载入 B 并播放）
  音量
```

## 3. 页面跳转

```text
上一句/下一句、单句循环、单曲循环
在查看 B、播放 A 时，都要先跳到 A 的页面。

跳转方式：
  load(A, autoplay=false)
  · 不重新 commitAudio
  · 不打断 A 的播放
  · 不改变 A 的播放位置
```

## 4. 波形

```text
时间来源：
  A 就是 B（B 正在播） → au.currentTime
  A 不是 B（B 只是查看） → B 当前选中行的时间
  没有选中行 → 最近一次标记 MARK

绘制：
  · B 正在播：LRC 模式播放时按帧刷新
  · B 不在播：只在选中/点击/缩放/平移时重画

点击波形：
  · B 正在播：seek B
  · B 不在播：只选中最近行 + 更新 MARK，不 seek A
```

## 5. 自动关闭单句循环

```text
触发：
  · 正在播 A，单句循环开着
  · 此时 load(B)，B != A

动作：
  · NH.loop = false
  · NH.LOOP_ROW = -1
  · 按钮文字恢复“单句循环”

不触发：
  · 查看 A 自己
  · 只切单曲循环
  · 只是播放/暂停
```

## 6. 实现要点

```text
1. 判断“B 是否就是 A”：
     String(NH.PLAYING) === String(NH.S.idx)

2. 上一句/下一句：
     没有 PLAYING → 直接返回
     B != A → await load(PLAYING, false)
     再 nextIdx/seekIdx

3. 播放/暂停：
     只操作 NH.au，不读 NH.S

4. 循环：
     没有 PLAYING → 直接返回
     B != A → await load(PLAYING, false)
     再切换
     加载 B 时检查是否需要关闭单句循环

5. 波形：
     viewStart / 播放头使用 waveTime()
     waveTime = B 正在播 ? au.currentTime : B 当前选中行时间

6. LRC 单击：
     只有在 B 正在播时才 seek
     否则只选择

7. LRC 双击：
     playLine(行号)：需要时 commitAudio(B)，seek，play
```

## 7. 边界

```text
· A 暂停时上一句/下一句：跳页并定位，不自动播放
· B 不在播时点单句循环：跳 A 页面，开启后从 A 当前句开始循环
· B 不在播时点单曲循环：跳 A 页面，只改开关
· 从未播放过：下方控件禁用，“开始”仍可用
· B 有未保存的 LRC 编辑：跳 A 前先 flush B
```
