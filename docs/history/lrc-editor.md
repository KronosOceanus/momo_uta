# LRC 编辑器（现状）

> 这是**当前行为**的说明，不是设计草案。
> 设计动机、放弃过的方案见 [`NOTES.md`](NOTES.md)「LRC 编辑器：设计动机与放弃的方案」。

## 1. 能做什么

```text
做
  · 在已有歌词上编辑：改文本、改时间戳、增删行、多选、粘贴
  · 没有 .lrc 的歌：从播放列表的歌词出发，补时间戳后保存
  · 点波形出标记 → 点行把标记写成该行时间
  · 保存回 <同名>.lrc（首次自动备份），导入外部 .lrc，另存为
  · 撤销/重做

不做
  · 自动打轴（Whisper / 强制对齐）
  · 波形编辑（剪切、淡入淡出）—— 不是 DAW
  · 行内拖动排序（接口有，界面没做）
```

## 2. 界面

```text
第 1 行  【开始】歌名                          振假名编辑模式 / LRC 编辑模式
第 2 行  【全选】【加行】【删行】   【保存】【另存为】【导入LRC文件】【恢复最初】
第 3 行  整体偏移 −0.5 −0.1 0.00 +0.1 +0.5                          跟随：开
第 4 行  波形（高 120px）
主区     行号 │ 时间戳 │ 文本（可编辑）        右侧罗马音隐藏，表格占满宽度
底部     上一句 / 播放 / 下一句 / 单句循环 / 重新匹配 / 速度
         自绘播放条：⟲10 ▶/⏸ 10⟳ 已播 ▬●▬ 总长 🔊
```

```text
进入 LRC 模式：
  · 歌词区换成「行号 + 时间戳 + 文本」
  · 波形出现；右侧罗马音隐藏
  · 切歌 / 点「重新匹配歌词」会退出该模式
```

## 3. 打轴交互

```text
① 点波形某处         → 设播放位置 + 出现标记（读数=该处时间）
② 点某一行           → 该行时间 = 标记时间，同时把音频跳到该行
③ 直接点行           → 音频跳到该行（不依赖标记）
④ 上一句 / 下一句     → 按行跳（跳过作词/作曲等 meta 行）
```

```text
键盘
  输入框内 Enter    光标处拆成两行
  非输入框 Enter    在选中行下面加一行
  ⌘A                全选
  Delete / ⌫        删除选中行
  行首 Backspace     把这一行接到上一行末尾（合并）
  ⌘Z / ⌘⇧Z         撤销 / 重做
  ⌘V（表格上）      粘贴多行，自动拆行；带 [mm:ss.xx] 前缀会解析时间
  空格              播放 / 暂停（焦点不在输入框时）
```

## 4. 整体偏移

```text
用途    LRC 时间轴整体比音频快/慢（换版本、剪过前奏）→ 不动文件，只挪对齐
控件    第三行：−0.5 / −0.1 / 0.00 / +0.1 / +0.5
作用    只影响播放高亮与跳句；不修改 .lrc
存储    data/curated/song_meta.json，每首歌一个值
提示    偏移 ≠ 0 时头部显示「偏移 +0.30s」，点一下清零
```

```text
区分：
  整体偏移（offset）  练习用，随时可清
  时间戳修正           真改 .lrc，要保存（有备份）
```

## 5. 文本编辑

```text
· 每行 { t, text }，行号 = 数组序号，自动重算
· 粘贴多行 → 按换行拆行，支持 [mm:ss.xx] 前缀
· 加行 / 粘贴的落点：多选 → 最后选中行之后；单选 → 该行之后；没选 → 末尾
· 多选：Ctrl/⌘ 点选、Shift 点选区间、Shift 拖拽框选
· 行内注音 漢字(かな) 当普通文本，原样显示、原样保存
· 空行允许存在（间奏）
```

## 6. 波形

```text
数据    ffmpeg → 8kHz 单声道 → 每 20ms 一对 (min,max)
        缓存 data/cache/wave/<md5>.<mix|vocals>.json，首次 0.3–1 秒，之后秒开
窗口    默认 5 秒、播放头居中、跟随播放
缩放    滚轮 2–10 秒
跟随    播放时窗口滚动；暂停冻结；可点「跟随：开/关」关掉
标记    只画每一句起点（暖橙色细线），不画刻度与行号
播放头  亮绿竖线，居中
性能    canvas 只在尺寸变化时重建；rAF 限 ~60fps，仅播放时重绘
```

```text
暂停状态下跳转、拖动进度条、载入完成都会重画波形
（否则画布会停在旧位置）
```

## 7. 保存 / 备份 / 恢复 / 导入

```text
实时保存      停手 1.5 秒自动写盘；状态显示「已保存 HH:MM:SS」（或「未保存…」）
主动保存      【保存】总是写一次，提示「已保存 N 行」
写入位置      <音频同名>.lrc（同目录）
备份          首次保存/导入前把原文件复制成 <同名>.lrc.bak，只做一次，不覆盖
恢复最初      【恢复最初】用 .bak 覆盖 .lrc，然后重新载入
导入 LRC      选外部 .lrc → 确认 → 直接覆盖当前歌词（覆盖前备份）→ 重新载入
另存为        原生保存对话框，写到任意位置（不备份）
```

```text
保存后同时更新歌词缓存（data/cache/lyrics），播放器立刻生效
行数为 0 时拒绝保存；时间戳倒退、未对齐的行照常保存
```

## 8. 撤销

```text
内存快照栈，最多 50 步
粒度：对齐一次、改文本一次、增删/粘贴一次
关掉窗口即清空（文件本身是结果）
```

## 9. 接口与实现

```text
GET  /api/wave/<idx>                     波形峰值
POST /api/lrc {action:"load", idx}       取 .lrc（没有则回退歌词缓存）
POST /api/lrc {action:"save", idx, lines}
POST /api/lrc {action:"backup", idx}
POST /api/lrc {action:"restore", idx}
POST /api/lrc {action:"import_lrc", idx, text}
```

```text
static/20-editor.js     编辑器 UI
static/10-app.js        波形绘制
static/30-playback.js   时间语义、播放条
core/lrcio.py           .lrc 读写、备份、恢复、JSON 歌词格式
core/waveform.py        峰值与缓存
service/lrc.py          保存/导入的业务编排
http/routes.py          /api/lrc 与 /api/wave
```

## 10. 边界情况

```text
音频读不出          波形区提示「无法生成波形」，仍可手工填时间
只读目录 / 无权限    保存失败提示，建议用「另存为」
超长音频（>30 分）   峰值约 360KB，仍可用
同一首歌在多歌单     编辑的是同一个文件，存一次两边都变
.lrc 与播放列表行数不同  载入时按播放列表对齐（避免左右错位）
网易云 JSON 歌词     能读（{"t":毫秒,"c":[{"tx":"…"}]}），保存时写成标准 LRC
```
