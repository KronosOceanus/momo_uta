# 歌单多选右键移动

> 状态：已实现（2026-11-27）。
> 目标：长歌单里选中的歌曲不靠拖拽，也能一次移动到另一个歌单。

## 1. 背景

歌单变长后，跨歌单拖拽有两个问题：

```text
目标歌单在列表顶部或很远的位置
拖动过程中要滚过大量歌曲
长距离拖动容易放错位置
```

现有拖拽仍然是精确定位的主要方式；  
右键移动补的是“批量搬运”入口。

## 2. 入口

```text
选中一首或多首
→ 右键
→ 移动到歌单 ▸
→ 悬停/点击展开二级菜单
→ 点击目标歌单
```

键盘：

```text
歌曲行获得焦点
→ Shift+F10（或 ContextMenu 键）
→ 移动到歌单 ▸
→ Enter / Space
→ ↑ ↓ 选择目标
→ Enter 移动
```

菜单顺序固定：

```text
移动到歌单 ▸
────────────
从歌单移除
```

“移动到歌单”在“从歌单移除”上方。

二级菜单支持：

```text
鼠标悬停 100ms 后展开
点击立即展开
离开后 180ms 关闭
键盘 Enter / Space 立即展开
```

## 3. 选择规则

沿用现有右键规则：

```text
右键已选中的歌曲
→ 保留当前多选

右键未选中的歌曲
→ 选择重置为这一首
```

移动使用 `NH.SELU` 中的全部选中歌曲，  
不因搜索过滤而改变选择集合。

右侧菜单文案：

```text
单选：移动到歌单 ▸
多选：移动选中的 N 首 ▸
```

## 3.1 键盘

歌曲行使用 `tabindex="0"` 可聚焦。

```text
Shift+F10 / ContextMenu
→ 打开右键菜单

菜单打开后
→ 自动聚焦「移动到歌单」

Enter / Space
→ 打开二级菜单
→ 自动聚焦第一个目标

↑ / ↓ / Home / End
→ 在目标歌单之间移动

Enter
→ 执行移动

← / Esc
→ 关闭二级菜单，回到「移动到歌单」

Esc
→ 关闭整个菜单，焦点回到歌曲行

Tab 离开菜单
→ 自动关闭菜单
```

## 4. 目标歌单

目标列表来自当前 `NH.PLS`：

```text
排除当前源歌单
默认歌单可以作为目标
显示名称和当前歌曲数
```

示例：

```text
移动到歌单 ▸
  默认歌单 (12)
  J-Pop (30)
  Kalafina (8)
```

规则：

```text
没有其他歌单 → 显示禁用的“没有其他歌单”
目标很多 → 子菜单最大高度 220px，超出滚动
靠近窗口右侧 → 自动向左展开
靠近底部 → 自动向上调整
```

## 5. 数据流

不新增后端接口，复用现有批量移动：

```json
{
  "action": "entries_move",
  "from": "源歌单 id",
  "to": "目标歌单 id",
  "uids": ["uid1", "uid2"]
}
```

后端 `PL.move_many()` 已支持：

```text
批量移动
去重
从源歌单删除
插入目标歌单
返回实际移动数量
```

接口返回：

```json
{"ok": true, "moved": 3, "lists": [...]}
```

插入位置：

```text
右键移动没有目标行位置
→ 追加到目标歌单末尾
```

拖拽跨歌单仍保留 `before` 精确插入。

## 6. 成功与失败

成功：

```text
清空选择
刷新歌单列表
聚焦源歌单中选中项后面的第一首
没有下一首则聚焦前一首
源歌单被移空则聚焦源歌单标题
toast：已移动 3 首到「J-Pop」
```

失败：

```text
保留选择
toast 显示后端错误
不假装移动成功
```

接口返回 `ok:false` 时不能先清空选择。

## 7. 不改变的状态

```text
正在播放歌曲的播放状态
当前查看歌曲
LRC 编辑状态
音量 / 播放模式
```

移动只改变歌单归属。

## 8. 边界

```text
1. 源歌单 = 目标歌单
   → 不作为目标显示

2. 默认歌单
   → locked 只限制改名/删除
   → 仍可作为移动目标

3. 目标已有同一首歌
   → 后端去重
   → 不重复添加

4. 目标歌单为空
   → 允许

5. 源歌单被移空
   → 保留空歌单

6. 搜索过滤后选中项
   → 按 selection 集合移动，不按当前 DOM 可见项截断

7. 接口失败
   → 保留选择，显示错误
```

## 10. 测试

已覆盖：

```text
1. 跨歌单无 before 时追加到目标末尾
2. 目标歌单排除源歌单
3. 成功移动发送 entries_move
4. 成功提示使用后端实际 moved 数量
5. 成功后清空选择
6. 接口失败保留选择并显示错误
7. moved=0 时保留选择并提示
```

仍建议手动验收：

```text
1. 多选右键移动
2. 右键已选中行保持多选
3. 右键未选中行重置为单选
4. 悬停 100ms 展开二级菜单
5. Shift+F10 打开菜单
6. 方向键切换目标，Enter 移动
7. 移动播放中的歌曲不改变播放状态
```
