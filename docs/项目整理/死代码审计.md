> 工具：pyflakes、vulture、跨文件符号搜索。
> 只审计，不修改。

## 0. 先说明

有一些“看起来没用”的代码不能直接删：

```text
HTTP 方法通过路由表动态调用
JS API 方法由前端调用
lyrics.py 是对外门面，import 是再导出
测试专用 set_file / set_cache_dir 是测试钩子
ObjC 回调参数受系统签名约束
```

下面只列真正值得处理的。

## 1. 实际 bug（不是死代码）

`src/momo_uta_app/logsetup.py`：

```python
def log_exception(exc_type, exc, tb):
    traceback.print_exception(exc_type, exc, exc_tb)
```

`exc_tb` 没有定义，应为 `tb`。

影响：

```text
未捕获异常走 sys.excepthook 时再次抛 NameError
```

这个应优先修。

## 4. 无用的 import / 重定义

### `src/momo_yomi/common.py`

```python
from .paths import (CACHE, CORPUS, CURATED, DATA, EVAL,
                    GOLD, REPORTS, ROOT, SOURCES, TABLES, TOOLS)

EVAL = ROOT / "eval"
GOLD = EVAL / "gold"
REPORTS = EVAL / "reports"
```

问题：

```text
EVAL / GOLD / REPORTS 先 import 后重新定义
CACHE / CORPUS / CURATED / DATA / SOURCES / TABLES / TOOLS
在当前文件内未使用
```

但不能直接全删，因为：

```text
tools/common.py 做 from momo_yomi.common import *
tools/* 依赖这些名字
```

应改为显式导出或只保留真正需要的名字。

## 5. 误报，不能删

```text

  → 路由表/HTTPServer 动态调用
```
