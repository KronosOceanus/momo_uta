
```text
universal2
或分别构建并合并
```

## 4. P2：full 的 ffmpeg 路径写死 — 已修复

```python
ffmpeg = Path("/opt/homebrew/bin/ffmpeg")
if ffmpeg.is_file():
    binaries.append(...)
```

问题：

```text
Intel Homebrew 在 /usr/local/bin
没有 ffmpeg 时静默不打进包

```

现在查找顺序：

```text
MOMO_FFMPEG

/opt/homebrew/bin/ffmpeg
/usr/local/bin/ffmpeg
```

full 缺失 ffmpeg 时构建直接失败。
