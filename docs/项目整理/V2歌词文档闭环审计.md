## 3. 待决策/风险

### 已决策：恢复备份不保留恢复前快照

```text
当前策略：恢复备份直接覆盖当前文件
不额外保存“恢复前”版本
```

```text
这是明确接受的行为，不再作为待修问题。
```

### 已决策：`save_rows` 不校验 rows

```text
nhlrc 的原则：
  写入端不校验
  读取端丢弃无法解释的条目
  歌词只是展示内容
```

```text
因此不增加 rows 结构校验。
坏数据在读取时按现有 parse 规则丢弃。
```

### 已决策：`save_rows` 的 `trans_lang` 继承旧文档

```text
core `LRC.save_rows` 的默认值改为 None
没传 trans_lang 时读取旧文档
旧文档也没有 → zh
```

```text
API 路径和直接 core 调用现在行为一致。
```

### P2：`expected_version` 可为空

`save_rows` 允许：

```text
expected_version=None
→ 直接覆盖
```

前端正常会传，但这是危险默认。

建议：

```text
API 的 save_rows 要求 version
或明确区分“新建”和“覆盖”
```

### P2：备份发生在渲染之前

`save_rows` / `import_text`：

```text
先 _backup_once
后 render / 转换
```

如果渲染抛错：

```text
备份已生成
文件没变
```

不破坏数据，但会产生无意义备份。

建议：

```text
先完成转换/校验
再备份
再写
```
